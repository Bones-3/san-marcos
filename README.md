# Veterinaria San Marcos

Sitio web y panel administrativo (demo) de la Veterinaria San Marcos.

## Stack

React 19, Vite, React Router 7, Bootstrap 5 / React-Bootstrap y Vitest + Testing Library.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
npm run test:run
```

## Acceso demo al panel

- URL: `/login-admin`
- Correo: `admin@veterinaria.com`
- Contraseña: `admin123`

> Demo sin backend: la sesión, usuarios, productos y carrito se guardan en `localStorage`.
> Las credenciales son de prueba y no deben usarse en producción.
